# agenda-administrativa-avhoto

Sistema de Gestão e Logística do **AvHoFlu Rio Tocantins**.

App de página única (`index.html`), servido pelo GitHub Pages, com sincronização
via Supabase e cache local para operar offline.

Clone da Agenda Administrativa do CHN-4, com escopo reduzido a um único meio e
sem a aba Garagem. Ver `CLAUDE.md` para as diretrizes de manutenção.
